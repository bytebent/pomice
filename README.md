# Pomice

A small modeller for smooth shapes made of maths primitives, for macOS. It makes
smooth props for Scalpellino, low-poly models for Mazzuola, and animated videos.

Personal project. **Design stage: nothing is built yet.** The docs, in the order to read them:

- [`CLAUDE.md`](CLAUDE.md): the hard rules for AI sessions (privacy, product, engineering).
- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md): the agreed design.
- [`docs/PLAN.md`](docs/PLAN.md): where the project stands: decisions, proposals, open questions, milestones.
- [`docs/HANDOFF.md`](docs/HANDOFF.md): how the user likes to work and decisions to keep (for a new AI session).
- [`docs/LOG.md`](docs/LOG.md): what was done, step by step.
